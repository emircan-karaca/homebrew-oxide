# homebrew-oxide

Homebrew tap for [Oxide](https://github.com/emircan-karaca/oxide-releases), a daemonless container engine for macOS on Apple Silicon.

```bash
brew install --cask emircan-karaca/homebrew-oxide/oxide
```

The Cask installs the signed and notarized `Oxide.app` from the release DMG and links the `oxide` command and shell completions. Upgrade with `brew upgrade --cask oxide`.
